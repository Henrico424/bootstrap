01 • Entendendo

O que é um framework?

Um framework é uma estrutura com ferramentas e padrões prontos que ajudam a desenvolver um projeto. O Bootstrap é um framework front-end: oferece classes CSS e componentes para montar interfaces sem escrever cada estilo do zero.

HTML

Estrutura

Define o conteúdo: títulos, textos, imagens, links e formulários.

CSS

Aparência

Controla cores, espaçamentos, tamanhos, fontes e posicionamento.

B

Bootstrap

Reúne classes e componentes reutilizáveis para acelerar o CSS.

Ideia principal: Bootstrap não substitui HTML nem CSS. Ele trabalha junto com eles e permite personalizações quando necessário.

02 • Layout

Containers

Containers centralizam o conteúdo e controlam a largura máxima da área. Compare os exemplos abaixo.

.container

Largura máxima muda conforme o tamanho da tela.

Área .container
<div class="container">
  Conteúdo centralizado
</div>

.container-fluid

Ocupa 100% da largura disponível.

Área .container-fluid
<div class="container-fluid">
  Largura total
</div>

.container-md

É fluido até atingir o breakpoint md.

Área .container-md
<div class="container-md">
  Responsivo a partir de md
</div>

04 • Sistema de grid

Layout responsivo

O grid do Bootstrap usa linhas (row) e colunas (col). As classes com breakpoints permitem mudar a quantidade de colunas conforme a tela.

Coluna 1
Coluna 2
Coluna 3
<div class="row g-3">
  <div class="col-12 col-md-6 col-lg-4">Coluna 1</div>
  <div class="col-12 col-md-6 col-lg-4">Coluna 2</div>
  <div class="col-12 col-md-12 col-lg-4">Coluna 3</div>
</div>
Celular

col-12: uma coluna por linha.

Tablet

col-md-6: duas colunas.

Desktop

col-lg-4: três colunas.

Vantagem

O layout se adapta sem criar várias folhas CSS.

05 • Navegação

Barra de navegação (navbar)

A navbar cria um menu adaptável. O botão de menu aparece em telas menores.

MinhaMarca
  • Início
  • Sobre
  • Contato
Prévia de uma navbar Bootstrap
<nav class="navbar navbar-expand-lg navbar-light bg-light">
  <div class="container">
    <a class="navbar-brand" href="#">MinhaMarca</a>
    <button class="navbar-toggler" data-bs-toggle="collapse"
      data-bs-target="#menu">
      <span class="navbar-toggler-icon"></span>
    </button>
    <div class="collapse navbar-collapse" id="menu">
      <ul class="navbar-nav ms-auto">
        <li class="nav-item">
          <a class="nav-link" href="#">Início</a>
        </li>
      </ul>
    </div>
  </div>
</nav>

A interação de abrir/fechar o menu depende do JavaScript do Bootstrap, incluído no final deste arquivo.

07 • Elementos gráficos da pesquisa

Padlet, infográfico e painel visual

A pesquisa também pode ser apresentada visualmente. Abaixo há três formatos de organização do conteúdo: um mural inspirado em Padlet, um infográfico-resumo e um mapa de relações entre os recursos do Bootstrap.

1. Mural de ideias (estilo Padlet)

Um mural organiza informações em cartões independentes, facilitando a leitura e a apresentação em grupo.

Conceito

O que é?

Bootstrap é um framework front-end com classes CSS e componentes prontos para acelerar a criação de interfaces.

Aplicação

Onde usar?

Em sites institucionais, portfólios, painéis administrativos, páginas de apresentação e protótipos.

Recursos

O que oferece?

Grid responsivo, containers, navbar, botões, cards, formulários, alertas e utilitários de espaçamento.

Resultado

Qual o benefício?

Menos código repetitivo, desenvolvimento mais rápido e aparência mais consistente entre páginas.

4. Comparativo visual: antes e depois

Sem framework

CSS escrito manualmente

  • É necessário criar estilos para cada componente.
  • Mais decisões de espaçamento e aparência.
  • Maior possibilidade de repetir regras.
Com Bootstrap

Classes reutilizáveis

  • Classes prontas para vários componentes.
  • Grid e breakpoints já definidos.
  • Menos CSS repetitivo no começo do projeto.
Importante: os cartões, diagramas e comparativos desta seção são elementos gráficos feitos em HTML e Bootstrap. Eles podem ser usados como base para montar um mural no Padlet ou slides de apresentação.

08 • Fechamento

Vantagens e cuidados

Vantagens

  • Acelera a criação de interfaces.
  • Oferece componentes reutilizáveis.
  • Ajuda a criar páginas responsivas.
  • Tem documentação e exemplos oficiais.

Cuidados

  • O visual padrão pode deixar sites parecidos.
  • É importante conhecer as classes usadas.
  • Personalizações podem exigir CSS próprio.
  • O projeto depende dos arquivos do framework/CDN.
Conclusão: Bootstrap aumenta a produtividade ao oferecer uma base pronta para layout e componentes. Ele é especialmente útil quando precisamos construir páginas consistentes e adaptáveis com rapidez, mas deve ser usado entendendo o que cada classe faz.
